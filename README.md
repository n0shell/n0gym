## ✨ Características Principales

- **📱 Experiencia Mobile & Nativa:** Disponible tanto en versión web responsive como en app nativa instalable para Android.

- **🏋️ Gestión de Rutinas:** Crea, edita y organiza tus rutinas de entrenamiento personalizadas de forma rápida.

- **📊 Historial Detallado:** Haz un seguimiento de tu evolución, pesos levantados y progreso sesión a sesión.

- **⚖️ Calculadora de Discos:** Herramienta rápida para calcular qué discos colocar en la barra según el peso deseado.

- **💾 100% Local & Privado:** Todos tus datos se almacenan de manera segura en tu dispositivo utilizando **IndexedDB**, sin necesidad de cuentas, servidores ni registros externos.
